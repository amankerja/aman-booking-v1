# Domain: Availability

## Tanggung Jawab
- SATU-SATUNYA SUMBER KEBENARAN kalkulator slot dan ketersediaan waktu (`AvailabilityService`).
- Menghitung slot kosong berdasarkan: jam operasional, buffer time sebelum/sesudah, block time, dan reservasi yang ada.
- Dilarang keras membuat algoritma kalkulasi ketersediaan kedua di frontend maupun di modul lain.
